# Repository workflow

- Use a feature branch and pull request for each feature.
- Do not commit feature changes directly to master or merge PRs unless requested by the user.
- Keep unrelated features separate and document dependencies between stacked PRs.
- Validate every branch independently and report checks and limitations in the PR.
- Preserve the original iOS project alongside the ZenGM browser game.
- Exclude generated builds, local leagues, dependencies, and temporary tooling from commits.
